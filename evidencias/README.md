# Evidencias del Sistema de Gestion de Logistica Portuaria

## Proyecto Final - Arquitectura de Microservicios

### Integrantes
- Gaspar Trejo Martinez
- Ana Merly Caballero Canul

### Contenido
Esta carpeta contiene las capturas y evidencias del desarrollo y funcionamiento del sistema.

Entre las evidencias se incluyen:
- Diagrama de arquitectura.
- Pantallas del sistema.
- Registro de liberaciones.
- Permisos del agente aduanal.
- Permisos del operador.
- Restricciones de acceso por rol.
- Capturas adicionales de pruebas.

### Objetivo
Mostrar visualmente el funcionamiento de los componentes principales del sistema y respaldar las pruebas realizadas durante el desarrollo.

Carrera: Ingenieria en Sistemas Computacionales.
